# Naming Standards

- `proxmox01`
- `k8s-cp1`
- `k8s-cp2`
- `k8s-cp3`
- `k8s-w1`
- `k8s-w2`
- `k8s-w3`
- `ops1`
- `svc1`

## Repository Names

- `homelab-infra-proxmox`
- `homelab-ansible`
- `homelab-k8s-platform`
- `homelab-apps`
- `homelab-docs`

## Namespace Names

Examples:
- `argocd`
- `ingress`
- `networking`
- `observability`
- `storage`
- `platform-system`
- `apps`

## General Standards

- use lowercase
- use hyphen-separated names for repos and Kubernetes objects
- use predictable role-based hostnames
