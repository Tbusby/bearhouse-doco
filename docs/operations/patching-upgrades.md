# Patching and Upgrades

## Principles

- patch on a defined schedule
- document upgrade plans before execution
- prefer controlled changes over ad hoc upgrades
- validate backups before major upgrades

## Scope

This applies to:

- Proxmox
- Ubuntu guest VMs
- Kubernetes versions
- platform services
- CI/CD tooling
- backup tooling
